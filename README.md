# Salary Slip Maker Website

A simple HTML-based Salary Slip Maker for creating and printing employee salary slips.

## Features

- Enter employee details
- Upload company logo
- Calculate salary breakup
- Enter paid days and salary calculation days manually
- Calculate salary deductions
- Preview salary slips
- Print or save salary slips as PDF
- Works in a web browser

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Use

1. Open `index.html` in your web browser.
2. Enter the employee details.
3. Upload the company logo.
4. Enter salary and deduction details.
5. Enter paid days and salary calculation days.
6. Preview the salary slip.
7. Print or save the salary slip as PDF.

## Project Structure

- `index.html` — Main salary slip website

## Deployment

This project can be hosted using GitHub Pages or Render as a static website.
